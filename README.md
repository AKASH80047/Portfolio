## ✨ Features & Architecture

- **📱 Fully Responsive Design**: Seamless adaptive rendering across Mobile, Tablet, and Desktop Web.
- **🤖 Generative AI & Multi-Agent Workflows**: LLM integrations (GPT-4o, Claude 3.5, Gemini 1.5 Pro), Vector RAG (Pinecone), and LangChain orchestration as engineered for **Handshake AI**.
- **🏗️ Clean Architecture**: Decoupled Presentation, Domain, and Data layers for scalable state management.
- **⚡ State Management**: Powered by Flutter Riverpod 2.x & BLoC.
- **🎨 Custom UI Design**: Tailored theme palette, compact mobile layout, smooth animations, and custom avatars.
- **🔗 Deep Links & Social Integration**: Direct links to GitHub repositories, LinkedIn, WhatsApp, Email, and downloadable Resume.
- **🎵 Featured Case Studies**: Dedicated showcases for commercial apps including *Handshake AI*, *Feel Every Beat* (Music Streaming), *AppleCart* (E-Commerce), *Expense Tracker*, *Dairy ERP*, *Exam Portal*, *MediPoints*, and *CRM Support Dashboard*.

## 🛠️ Tech Stack & Dependencies

- **Framework**: Flutter 3.x (Dart 3.x)
- **State Management**: `flutter_riverpod`
- **Routing**: `go_router`
- **Networking**: `dio` & REST APIs
- **Hosting**: Firebase Hosting (`akash-pandey-portfolio.web.app`)
- **Icons & UI**: Native Vector BrandIcons & Material 3
- **Utilities**: `url_launcher`

## 🏃 Getting Started

### Prerequisites

- Flutter SDK (>= 3.0.0)
- Dart SDK (>= 3.0.0)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AKASH80047/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**:
   ```bash
   flutter pub get
   ```

3. **Run locally**:
   ```bash
   flutter run -d chrome # Web
   # or
   flutter run -d macos  # Desktop
   # or
   flutter run           # Mobile Emulator/Device
   ```
